    Scope

    On macOS the scope hangs on the large reads the system normally issues: the file list shows up, but a copy from the Finder stays at 0 bytes. The fnirsi.py script, in this viewer's folder, reads 4 kB at a time without cache and always works. It copies the new files from the Waveform and Screenshots folders to measurements/fnirsi_YYYYMMDD, and never overwrites a different file with the same name (the scope restarts its numbering at 1 after a deletion). Then open that folder here with Open folder.

    Checking the connection…

    To pick files by thumbnail, download them and delete them from the scope, start the viewer with python3 fnirsi.py viewer. Without it, the command below copies the files from the terminal.

    python3 fnirsi.py download --csv --eject

    Before plugging in the USB cable, put the acquisition in STOP and save everything you need. If a read hangs, the script gives up after 30 s: unplug and replug the cable and run it again. Unplug the USB cable from the Mac while measuring: the ground return through the Mac adds a square wave of about 1 kHz on the ground.

    How the file is read

    The file is not an audio WAV: it is the scope's own format. A table at the start points to three sections (settings, screen thumbnail, data). Samples are 16-bit; the 8-division screen height is 12800 counts, that is 1600 counts per division.

    From the settings the viewer reads: which channels are on, each channel's V/div (in microvolts), the zero position (in pixels, 25 per division), the time per division (in picoseconds), the sample rate and the number of samples per channel. Every value is big-endian, samples included: first all of CH1, then all of CH2. Each channel holds several acquisitions of the same 12-division window, saved one after the other (2 at 1 ms/div, up to 10 at 50 ns/div): the first is the one the screen showed, the others can be picked under Acquisition. The first samples of each acquisition are empty and are not shown. If a value read from the file is not plausible, the field is marked for checking and you can correct it by hand. Parts outside the screen are clipped by the scope and show up as flat sections at the edge.
